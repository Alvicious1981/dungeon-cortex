# Dungeon Cortex — Equipment Sprite Pack

Pack inicial de sprites gráficos para `Dungeon Cortex`.

## Contenido

- 1 spritesheet SVG con 24 sprites de equipo.
- 1 manifest JSON con identificadores, categorías y coordenadas.
- 1 guía de uso en `docs/assets/SPRITES_USAGE.md`.

## Ruta pública

```text
/assets/sprites/equipment/equipment-spritesheet.svg
/assets/sprites/equipment/equipment-manifest.json
```

## Cómo comprobarlo

1. Arranca el proyecto.
2. Abre esta ruta en el navegador:

```text
http://localhost:3000/assets/sprites/equipment/equipment-spritesheet.svg
```

3. Si aparece una cuadrícula de sprites, la integración de assets funciona.

## Nota

Estos sprites son arte inicial de prototipo. Sirven para inventario, equipo, botín, tienda o fichas de objetos. Más adelante se pueden sustituir por arte final manteniendo los mismos ids y rutas.
