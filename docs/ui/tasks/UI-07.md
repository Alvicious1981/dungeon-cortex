## Objective
Create a compact minimap using the same map state and visibility authority as the existing full map.

## Repository facts (verified 2026-10-01 — re-verify in preflight)
- `components/exploration/DungeonMapVTT.tsx` is the SVG renderer (pan, zoom, fog of war, room markers, player token). Its data
  comes from `lib/hooks/useDungeon.ts`, which generates the tile grid and the memoized FOV from `Location.seed` through
  `lib/rules/dungeon.ts`. Tiles are not stored in the database.
- Related surface: `components/exploration/ExplorationMap.tsx`. Tests: `tests/components/DungeonMapVTT.test.tsx`,
  `tests/components/ExplorationMap.test.tsx`, `tests/rules/dungeon.test.ts`.
- Everything under `components/exploration/map/` (`HexTile`, `WildernessMapController`, `WildernessMapVTT`) and
  `components/exploration/WildernessHUD.tsx` belongs to the wilderness subsystem, which the project switched off pending a
  rules decision (`AGENTS.md`, "The whole wilderness subsystem"); today only tests import it. It is not the dungeon map. Do not
  touch or revive it, and do not mistake it for the map this task builds on.

## Inspect
- `components/exploration/DungeonMapVTT.tsx`
- `lib/hooks/useDungeon.ts`
- `lib/rules/dungeon.ts` (FOV and discovery)
- visited nodes and map rules
- callers and tests

## Do not create
- a second dungeon generator;
- an independent FOV;
- a second map-state authority.

## The minimap shows only legitimate knowledge
- player position;
- known geometry;
- known and visited nodes;
- the current context allowed by the existing FOV and discovery.

Never reveal an undiscovered room or node. A leak through a prop, a title, an `aria-label` or the DOM counts as a leak.

## Full-map regression
Preserve pan, zoom, keyboard operation, centering and FOV. Extract a small shared renderer or data layer only if it clearly
reduces real duplication.

## Targeted tests
Player, visited/known data, hidden undiscovered data (assert it is absent from the output, not only invisible), FOV, compact
rendering, full-map regression. Run with `pnpm exec vitest run --maxWorkers=2 <paths>`; falsify what you add.

## Acceptance
- Single map authority; no information leak; compact accessible minimap with a text alternative; full map intact.
