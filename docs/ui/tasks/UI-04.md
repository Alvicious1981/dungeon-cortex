## Preserve
Everything the sheet renders today, in particular:

Identity: name, class, level, race, optional background and alignment.
Core: AC, HP, initiative, speed, proficiency bonus, passive perception.
Abilities: STR, DEX, CON, INT, WIS, CHA.
Combat: attacks, damage, modifiers, traits.
Magic: existing spell slots.
Inventory: existing inventory content.
Progression and state: XP, exhaustion, level-up and profile editing as they exist.

Show a value only if the data carries it. Optional and null values render as an explicit absence, not as a made-up number.

## Prepare for
UI-05 equipment integration: leave a clear, empty place in the layout for it. Do not implement the ragdoll.

## Do not
- Recalculate mechanics. AC, modifiers and bonuses are read, never recomputed in React.
- Remove existing data.
- Add equipment authority.
- Implement spatial inventory.

## Targeted tests
Identity, metrics, abilities, attacks, spell slots, inventory, optional/null values and accessibility, reusing the tests above.
Run with `pnpm exec vitest run --maxWorkers=2 <paths>`; falsify any test you add.
